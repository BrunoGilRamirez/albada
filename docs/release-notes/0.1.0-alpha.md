# Albada 0.1.0 alpha

Albada 0.1.0 is an opt-in Windows desktop alpha for local-first personal
planning and journaling.

## Included

- Goals, projects, standalone tasks, hierarchy, dependencies, and explainable
  effort-weighted progress.
- Deadline warnings, daily planning, flexible blocks, sessions, and local
  notifications.
- Independent journal entries and a separate private therapy collection.
- Read-only legacy import, selective Markdown export, embedded Typst/PDF
  export, and local backup/restore.
- Reproducible frontend and Rust verification in GitHub Actions, plus unsigned
  Windows MSI and NSIS installers.

## Important expectations

- This is an early alpha for one local Windows user. There are no accounts,
  synchronization, telemetry, or remote application services.
- Start with a new public-alpha database. The public 0.1.0 lineage does not
  upgrade private development or pre-alpha databases and does not restore their
  backups.
- Back up your local data before installing a newer alpha. Downgrades are not
  supported.
- Installers are unsigned. Windows may show an unknown-publisher or
  untrusted-app warning; inspect the release source before continuing.
- Do not attach databases, backups, journal entries, therapy content, or other
  personal records to issues or pull requests.

## Verification baseline

The release workflow runs typecheck, lint, formatting, frontend tests, Rust
formatting and linting, Rust tests, and the production Windows bundle before a
draft GitHub Release is created.

## Feedback

Use GitHub Issues for small, reproducible reports with synthetic data. Alpha
support is voluntary and best-effort with no service-level guarantee. See
[`SECURITY.md`](../../SECURITY.md) for private vulnerability reporting.
